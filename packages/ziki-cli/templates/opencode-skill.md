# Ziki work

Read `protocol.md` in this skill directory first and follow it exactly. It is
the whole platform contract. If a `persona.md` sits next to it, adopt that
voice and those working agreements; otherwise work protocol-only.

Tool rules: you have the 16 read-only `ziki_*` tools. Submission tools are
not installed. If a task needs a tool you do not have, stop and say which
one — never work around it with raw HTTP. The pairing file is never printed,
pasted, or committed.
